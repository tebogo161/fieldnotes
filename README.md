# Fieldnotes

A responsive, multi-page student blog and portfolio about learning Computer Systems Engineering. The content is based on the supplied study-skills document and edited for clarity and readability.

## Pages

- `index.html` — homepage and featured posts
- `about.html` — student profile and goals
- `journal.html` — reflections and article listing
- `journey.html` — first-year learning reflection
- `teamwork.html` — group-work reflection
- `study-habits.html` — study routine reflection
- `projects.html` — coursework and developing skills
- `resources.html` — practical study tips

## Run locally

Open `index.html` in a browser. No build step or package installation is required. Bootstrap 5.3.3 is loaded from jsDelivr, so an internet connection is needed for Bootstrap styling and the responsive navigation menu.

## Technology

- HTML5 for independent, linked pages
- Bootstrap 5.3.3 for responsive layout and navigation
- `styles.css` for the shared visual theme and responsive styling

## Accessibility and responsive design

Pages use semantic landmarks, a skip link, visible keyboard focus, descriptive navigation labels, and reduced-motion support. Layouts were checked at viewport widths from 320px to 1440px.

## Privacy

Personal contact details, postal address, and date of birth from the source document are intentionally not published.
